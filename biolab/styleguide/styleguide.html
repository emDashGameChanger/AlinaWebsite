Colour

Lavender is a wash and an accent, never a wallpaper. Text is always --ink, --ink-soft or a dark lavender. Use the token, never the hex, in CSS.

  • --paper#fbfaffPage background
  • --surface#ffffffCards, tables
  • --ink#2b2640Body text
  • --ink-soft#575170Secondary text
  • --wash-50#f5f2fcBands, zebra rows
  • --wash-100#ece6f8Tinted panels, code
  • --wash-200#ddd4f0Hairlines, borders
  • --lav-300#b8a9dcDecorative strokes
  • --lav-500#8b78c6Motifs, chart bars
  • --lav-700#5b4b8aLinks, accents
  • --lav-900#392f60Headings

Type

Source Serif 4 for headings, stats and the article intro; Inter for everything else; system monospace for code.

Heading one, Source Serif 4

Heading two, Source Serif 4

Heading three, Source Serif 4

Body copy is Inter at 1rem with a 1.65 line height and a 46rem measure, so lines stay readable on a large screen.

Small and secondary text in the muted ink colour, for captions and footnotes.

Chinese motifs

Decorative only: never behind body text, always low contrast, always aria-hidden or a CSS background. At most one large motif and two small ones per page. All four are generated by site-design-system/scripts/make_motifs.py.

One primary button per view; the ghost style for the secondary action.

Card grid

Use .cards--2 for four or fewer, .cards--feature for three. Every card links to a page and has a kicker, a title and one or two sentences. Image needs alt and width/height.

    One or two sentences, no more.

    Read the write-up

Breadcrumb and page header

Top of every page below the landing. The h1 is the page title and .lede is the one-sentence subtitle.

  2. Molecular Docking
  3. Screening CYP51

One-sentence subtitle that says what the reader gets.

Article text

Inside article.prose. First paragraph gets .intro. Steps are h2 (the fret ornament is added automatically); use h3 only inside a step.

Opening paragraph in the serif, a little larger than the body.

Step 1: A heading

Body text in Inter at a comfortable measure, with a link, bold and italic.

  • Lists keep the same rhythm.
  • Second item.
HTML
<article class="prose sg-inline">
  <p class="intro">Opening paragraph in the serif, a little larger than the body.</p>
  <h2>Step 1: A heading</h2>
  <p>Body text in Inter at a comfortable measure, with <a href="#prose">a link</a>, <strong>bold</strong> and <em>italic</em>.</p>
  <ul><li>Lists keep the same rhythm.</li><li>Second item.</li></ul>
</article>

Figure

Charts and screenshots. Always alt text; add a figcaption when the picture needs explaining.

HTML
<figure class="figure">
  <img src="molecularDocking/images/trScreenResults.svg" alt="Bar chart of the top 10 predicted binding affinities against TR" width="680" height="420" loading="lazy">
  <figcaption>Optional caption in the muted colour.</figcaption>
</figure>

Data table

Always inside .table-wrap (scrolls on phones, keyboard-focusable). th scope=col. Add class num to numeric columns.

DrugPredicted affinity
digitoxin-13.0 kcal/mol
dutasteride-12.6 kcal/mol
HTML
<div class="table-wrap" role="region" tabindex="0" aria-label="Example table">
  <table class="data-table">
    <thead><tr><th scope="col">Drug</th><th scope="col" class="num">Predicted affinity</th></tr></thead>
    <tbody>
      <tr><td>digitoxin</td><td class="num">-13.0 kcal/mol</td></tr>
      <tr><td>dutasteride</td><td class="num">-12.6 kcal/mol</td></tr>
    </tbody>
  </table>
</div>

Callout

For the AI-use note (last section of every write-up) and for scope/safety notes. Not for decoration.

A quick note on how this got built

Say plainly where Claude Code did the work and which decisions were Alina's.

HTML
<aside class="callout" aria-labelledby="built-title">
  <h2 id="built-title">A quick note on how this got built</h2>
  <p>Say plainly where Claude Code did the work and which decisions were Alina's.</p>
</aside>

Code block

Commands the reader will copy. Plain text inside pre.code; no syntax colours.

export PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
HTML
<pre class="code">export PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin</pre>

Pose card

Pairs of renders that link to the full-size image. Wrap the grid in .pose-grid.wide so it breaks out of the reading column.

HTML
<div class="pose-grid wide">
  <figure class="pose-card">
    <div class="pose-pair">
      <a href="molecularDocking/images/ptr1poses/alectinib.png" target="_blank" rel="noopener"><img src="molecularDocking/images/ptr1poses/alectinib.png" alt="Alectinib docked pose, stick representation" width="900" height="700" loading="lazy"></a>
      <a href="molecularDocking/images/ptr1posesSurface/alectinib.png" target="_blank" rel="noopener"><img src="molecularDocking/images/ptr1posesSurface/alectinib.png" alt="Alectinib docked pose, surface representation" width="900" height="700" loading="lazy"></a>
    </div>

</div>

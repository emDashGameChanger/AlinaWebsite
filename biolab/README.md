# biolab

Molecular docking tooling and a worked example for the BioMedBound project.

## What's here

- `config.txt` — AutoDock-Vina-GPU config for the example docking run
- `receptor.pdbqt`, `ligand.pdbqt`, `ligand.sdf` — prepared example receptor/ligand
- `ligand_out.pdbqt`, `output.pdbqt`, `log.txt` — output/log from the example run
- `3I3R.pdb`, `3I3R_out/` — fpocket pocket-detection output for receptor 3I3R (59 candidate pockets)
- `environment.yml` — conda env spec (`pymol-open-source`, `openbabel`)
- `setup.sh` — reproducible build script for fpocket + AutoDock-Vina-GPU-2.1

Not committed to git (machine/GPU-specific, regenerated by `setup.sh`):
`AutoDock-Vina-GPU-2-1` (compiled binary), `OpenCL` (symlink), `Kernel1_Opt.bin` /
`Kernel2_Opt.bin` (OpenCL kernel caches), `vendor/` (cloned upstream source).

## Setup

```bash
bash setup.sh
```

This installs apt prerequisites (build-essential, cmake, boost, CUDA toolkit),
builds fpocket, creates the `biolab` conda env, and builds AutoDock-Vina-GPU-2.1
from source — following the same steps documented in the website's
[Software Install tutorial](../molecularDocking/softwareInstall.html).

Already built on this machine? `setup.sh` is idempotent — it skips steps that
are already done. Use `bash setup.sh --force` to rebuild from scratch.

## Running the example

```bash
conda activate biolab
./AutoDock-Vina-GPU-2-1 --config config.txt
```

For the narrated walkthrough of what this example does and why, see the
tutorials on the website: [Hello Tools Part 1](../molecularDocking/Hello1.html)
and [Hello Tools Part 2](../molecularDocking/Hello2.html) (fpocket-guided
targeted docking).
